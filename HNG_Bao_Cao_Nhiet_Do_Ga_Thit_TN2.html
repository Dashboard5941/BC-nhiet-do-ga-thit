⚙ Kết nối dữ liệu Google Sheets

Kiểm tra
Một API key là đủ cho một file gồm 20 sheet chuồng. Google Cloud → bật Google Sheets API → tạo API key. Google Sheet phải được phép đọc bằng API key; với dữ liệu riêng tư, nên dùng OAuth hoặc proxy có xác thực thay vì công khai bảng tính. Nên giới hạn API key theo HTTP referrer (GitHub Pages) và chỉ bật quyền gọi Sheets API.
Bảo mật: API key phía trình duyệt có thể được xem trong yêu cầu mạng; đừng đưa key vào mã HTML hoặc dùng bảng tính chứa dữ liệu nhạy cảm.

Chưa kết nối. Bạn vẫn có thể xem bản dữ liệu Excel đã được nhúng.
